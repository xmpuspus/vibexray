# Code of conduct

## Our pledge

We want this project to be open and welcoming. We ask every participant to treat others with respect.

## Expected behavior

- Be kind and patient with other people.
- Accept feedback on your work in good faith.
- Focus on what helps the project and its users.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Public or private threats.
- Publishing the private information of others.

## Enforcement

Maintainers remove comments, commits, and issues that break this code. They can block repeat offenders.

Report a problem by opening a private security advisory on the [GitHub repository](https://github.com/xmpuspus/vibexray/security/advisories/new). Maintainers review every report and keep the reporter private.
